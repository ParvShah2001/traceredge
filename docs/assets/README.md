# 📸 TracerEdge Media & Visual Assets

This directory hosts documentation screenshots, architecture diagrams, and demo recordings for TracerEdge.

### Recommended Files to Add:
1. `dashboard_preview.png` (or `.gif`): Full screener table view showing live price updates, sticky symbols, and index bar.
2. `query_builder_preview.png`: Screenshot of the Custom Formula Modal configured with rules (e.g., Bullish Gap-Up / Open=Low).
3. `chart_modal_preview.png`: TradingView candlestick modal displaying emerald/rose candles, volume histogram, and OHLC hover legend.
4. `social_preview.png`: 1280x640 banner for GitHub repository Social Preview settings.
